9

Mail — Gmail and Outlook

Feature

Email joins the rest of your day. Connect one mailbox or several, from either service, and the inbox lives on a card in the Life Hub rather than in a tab of its own.

  • One button finds what is in a message — the meetings, the deadlines, the things you have been asked to do, who is involved, and whether it needs a reply. Each comes back with the button that acts on it.
  • Dates are worked out in code, not guessed — the model only quotes the words the email used, and the calendar is resolved against the day the message was sent.
  • Highlight anything and turn it into a task, an event, a project line or a drafted reply, through a review card you edit first.
  • Write an email by describing it — tell the composer what to say, then edit what it gives you.
  • It never sends, files or deletes anything on its own, and permanent deletion is impossible because the permission is never requested.

9

Outlook: three things Microsoft Graph would not answer

Fix
  • The folder index asked for wellKnownName, a property that personal Microsoft accounts do not carry — one rejected request took out every listing, so a correctly connected mailbox looked empty.
  • Opening a message asked for contentId on the base attachment type instead of the file-attachment type it belongs to, so no Outlook message would open at all.
  • Opening a conversation filtered and sorted in the same request, which Exchange refuses; the ordering is done locally now.
9

Read and unread, without a refresh

Fix

Marking a message read updated the provider but not the row in front of you, so nothing changed until the next poll. The flag is translated to the field the list actually renders now, and the unread counts on the card and in the sidebar move with it.

1

Carry your setup from one Pulse to another

Feature

Everything you have made — trips, the launchpad, folders, to-dos, habits, projects and conversations — exports to a single file and imports into another copy. A browser keeps this per origin, and the desktop app serves itself from a different port, so without a file nothing crosses between them.

Caches are deliberately left out: they belong to an account the new copy has not connected.

Launchpad, rebuilt over a week

Improvement

A fortnight of work on the shelf, in one line: it finds the applications you actually have installed and notices new ones while it is open; browser-installed web apps count as apps; any icon can be replaced, including .icns files; every icon is one size with a background of its own; folders can be reordered and things filed into them in a tap; and anything can be renamed to what you call it.
